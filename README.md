Консольный набор утилит калькулятор и конвертер.

Функционал:

1)Калькулятор поддерживает операции +,-,/,*,//,% (включая унарные + и -)
2)Конвертер переводит одни величины в другие, список величин:
1. Масса (кг, г)
2. Расстояние (мм, см, м, км)
3. Температура (кельвины, цельсии, фаренгейты)

Как использовать:

1)Открыть терминал в папке src
2)Создать окружение: python -m venv venv
3)Использование калькулятора: python -m toolkit calc "ВЫРАЖЕНИЕ"
4)Использование конвертера: python -m toolkit convert ЗНАЧЕНИЕ --from ВЕЛИЧИНА --to ВЕЛИЧИНА
